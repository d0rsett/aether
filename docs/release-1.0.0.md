# Aether 1.0.0 — подготовка выпуска

Статус — локальная подготовка версии. Дата публикации пока не назначена.

## Описание выпуска

Aether 1.0.0 объединяет Markdown-редактор, связанные заметки, граф и визуальные доски Canvas в локальном рабочем пространстве. Заметки, вложения и доски остаются обычными файлами хранилища.

В этом выпуске добавлены доски JSON Canvas, карточки заметок и медиа, группы, связи, редактирование заметок на полотне, импорт, привязка и история действий. Доски сохраняются автоматически с проверкой внешних правок. Переименование файлов обновляет ссылки на них в досках через журнал восстановления.

Проводник получил единые меню и настраиваемые значки файлов и папок. Настройки используют собственные выпадающие списки, выделение текста следует выбранной палитре.

## Приёмка перед публикацией

- Пройти нативные сценарии Windows на соответствующей тестовой сборке.
- Вручную проверить macOS на отдельном тестовом хранилище, включая выделение текста, выпадающие списки, Canvas, импорт и перезапуск с черновиком.
- Проверить обмен доской с Obsidian в обе стороны, включая связи, группы, вложения и переименования.
- Собрать Windows x64 и универсальную macOS из одного коммита, добавить контрольные суммы.
- Проверить установку и запуск скачанных пакетов на обеих платформах.
- Исключить из публикации локальные тестовые заметки и правки демонстрационного хранилища.
- Выбрать лицензию проекта до заявления условий распространения.

## Ограничения для описания релиза

Сборки не подписаны, macOS не нотарифицирована. Автообновление не настроено. Linux не проверен. Карточки веб-страниц открывают ссылки во внешнем браузере. Плагины Obsidian, Bases и синхронизация не реализованы.

Завершение сборки и модульных тестов само по себе не закрывает нативную и совместимостную приёмку.
