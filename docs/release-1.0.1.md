# Aether 1.0.1

Исправления Live Preview и переименования файлов в облачных папках на Windows.

## Изменения

- При отключённом переносе строк блоки Live Preview ограничены видимой шириной редактора. Изображения и другие встроенные блоки больше не смещаются к середине самой длинной строки. Ширина пересчитывается при изменении размеров редактора.
- Переименование заметок и вложений на Windows использует штатное перемещение вместо создания жёстких ссылок. Это устраняет ошибку iCloud 396, сохраняя защиту от перезаписи существующих файлов и журнальное восстановление операций.

## Проверка

Пользователь подтвердил работу обоих исправлений на локальной Windows-сборке перед обновлением номера версии. Добавлены регрессионные тесты для ширины предпросмотра, коллизий имён и перемещения файлов с кириллицей.

Все 189 frontend-тестов прошли. Из Rust-тестов прошли 62; один тест восстановления с созданием жёсткой ссылки ограничен средой и исключён из повторной проверки. Нативный E2E-набор не запускался.

## Загрузки и ограничения

Windows x64: установщик и отдельный EXE. Для запуска требуется WebView2. Сборки не подписаны. Обновление не добавляет собственную синхронизацию: файлами iCloud управляет облачный провайдер.

macOS-сборка требует отдельной сборки и проверки; исправление перемещения через Windows API на неё не распространяется.
