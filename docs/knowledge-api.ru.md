## Контракт и ответственность

`src/services/api.ts` определяет типизированные вызовы frontend; Rust-команды в `src-tauri/src/lib.rs` проверяют активное хранилище и передают правила файлов/индекса в `aether-core`. Markdown — источник истины; SQLite FTS5 восстанавливается. Устаревшие ответы после смены заметки/хранилища отбрасываются.

| Область      | Вызовы и поведение                                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Поиск/индекс | `search_notes`, `inspect_note`, `index_status`; ограниченные результаты, параметризованные фильтры, фоновое обновление                    |
| Ссылки       | `resolve_link`, `link_suggestions`, `locate_anchor`; пути, псевдонимы, заголовки/блоки и явная неоднозначность                            |
| Рендеринг    | `render_markdown`, `render_note_fragment`; текущий буфер в инертные узлы и диапазоны без записи                                           |
| Вложения     | `read_image`, `read_media`; проверенные пути, форматы и ограниченное чтение                                                               |
| Свойства     | `property_catalog`, `property_types`, `set_property_type`; ограниченные подсказки, общие типы и явная запись настроек с проверкой ревизии |
| Шаблоны      | `template_folder`; настройка папки Obsidian с проверенным запасным значением                                                              |
| Транзакции   | `preview_rename`, `rename_preview_page`, `apply_rename`, `rename_state`, `undo_rename`; планы сервера и восстанавливаемые журналы         |

Точные поля запросов/ответов заданы TypeScript-контрактом и сериализацией Rust. При изменении IPC обновляйте их вместе.

## Ссылки и индекс

Wiki-разрешение проверяет пути от корня, соседние заметки, уникальные имена и затем короткие YAML-псевдонимы. Явные относительные пути остаются относительными и не выходят из хранилища. Подписи не определяют идентичность; якоря заголовков/блоков остаются отдельными целями. При нескольких совпадениях возвращаются кандидаты.

Поиск использует Unicode61 и экранированные префиксные термы; ввод не исполняется как SQL или произвольный FTS. Фильтры пути/тега/свойства передаются параметрами. Маркеры совпадений становятся текстом/mark в React. Страницы поиска ограничены; подсказки ссылок содержат фактические пути и необязательные подписи.

Watcher обновляет индекс и дерево без сохранения заметок и подмены dirty-буферов. План переименования использует реальные файлы, не доверяя кешу. Ошибка индекса не отменяет завершённую файловую транзакцию.

## Ограничения и рабочий стол

Локальные растровые изображения ограничены 8 МиБ; PDF/аудио/видео — 64 МиБ с проверкой формата. Каталог свойств ограничивает обход, заголовки, имена и значения; YAML-ссылки не раскрываются. Настройки шаблонов читаются с лимитом и проверкой хранилища.

Системные диалоги папок принимают необязательный `language: "ru" | "en"`; без него сохраняется русский для старых вызовов. Ошибки остаются структурированными; поддерживаемые сообщения переводятся на границе frontend. Общего доступа к файловой системе/shell у рендерера нет.
